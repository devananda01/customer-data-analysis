# Customer Data Analysis

A data analysis project using KNIME and Power BI to explore customer behaviour and identify patterns in the dataset.

## What I Did

- Cleaned and prepared customer data
- Handled missing and inconsistent values
- Used K-Means clustering to group customers
- Built a linear regression model to predict combined ratings
- Evaluated the regression model
- Created visualisations and a dashboard in Power BI

## Tools

- KNIME
- Power BI

## Files

- `customer_analysis.knwf` - KNIME workflow
- `customer_analysis.pbix` - Power BI report
